Keep each real shelf photo beside a JSON file with its normalized spine boxes and printed titles.
Use a null title for a spine whose title cannot be read; it counts for detection coverage but should never receive a title callout.
With the dev web and API servers running and OPENROUTER_API_KEY set on the API server, use npm run eval:record -- crai-spines-17 to record the labels the app actually shows in eval/results. Run npm run eval to measure recall, precision, and wrong-spine labels. The release gate fails until every fixture has predictions, at least one label is shown, and no label is on the wrong spine.
Use npm run eval:record-boxes -- crai-spines-17 to save and parse a real Perceptron box response for the model contract check.
Do not put invented predictions in the golden set.
